# NoSwipe

Плагин (dylib) для iOS-игр, установленных через IPA и подписанных своим сертификатом (LCSign, Sideloadly, eSign и т.п.). Защищает от случайного сворачивания игры свайпом снизу: первый свайп только показывает индикатор «домой», а свернуть игру можно вторым свайпом. Так же работают игры из App Store, у которых эта опция включена.

Плагин не требует джейлбрейка. Он не использует Substrate/Logos, а подменяет методы напрямую через Objective-C runtime.

## Два варианта

В архиве лежат два файла. **Ставь только один из них, не оба сразу**, так как они меняют одни и те же методы.

| Файл | Индикатор «домой» | Когда использовать |
|---|---|---|
| `NoSwipe_A.dylib` | Остаётся видимым | **Начни с него.** Подходит, когда нужно просто защититься от случайных свайпов и ты не против полоски внизу экрана. |
| `NoSwipe_B.dylib` | Скрывается через несколько секунд | Бери, если с вариантом A первый свайп всё равно сворачивает игру. Подходит и тем, кому мешает полоска внизу экрана. |

### Как выбрать

1. Установи `NoSwipe_A.dylib` и проверь в матче: первый свайп снизу должен лишь показать индикатор.
2. Если игра по-прежнему сворачивается с первого раза, удали A, поставь `NoSwipe_B.dylib` и проверь снова.
3. Если не помогает ни один вариант, значит игра перехватывает управление жестами иначе. Открой Issue и напиши название игры и версию iOS.

> Поведение жестов зависит от версии iOS и от самой игры, поэтому какой вариант сработает, заранее предсказать нельзя. Универсальной гарантии нет.

## Как работает

Плагин переопределяет у главного ViewController игры два метода:

- `preferredScreenEdgesDeferringSystemGestures` возвращает `UIRectEdgeBottom`, то есть нижний системный жест откладывается до второго свайпа;
- `prefersHomeIndicatorAutoHidden` возвращает `NO` (вариант A) или `YES` (вариант B).

Класс контроллера определяется автоматически при запуске игры. Для Unity-игр дополнительно патчатся `UnityViewController` и `UnityDefaultViewController`.

## Установка через LCSign

1. Сохрани нужный `.dylib` в приложение «Файлы».
2. В LCSign открой проект игры, в блоке **Injected Plugins** нажми **+ Add** и выбери файл.
3. Примени изменения (Pending changes) и нажми **Sign & Install**.

В Sideloadly: **Advanced Options → Inject dylibs**.

## Ограничения

- Только arm64, iOS 13 и новее.
- Работает только для приложений, которые ты подписываешь сам.
- Плагин не тестировался на всех играх и версиях iOS.
